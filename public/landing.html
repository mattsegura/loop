How it works

One project.
Two agents.

Save a decision in Claude. Open Codex tomorrow and ask it to continue. Here’s what that handoff can look like.

Example handoffLaunch brief
Claude CodeSaved decision

“Remember that the launch brief is for existing customers.”

CodexNext session

“I found the audience decision. I’ll open with what’s changing for current customers.”

Claude CodeSaved instructions

“Save our brief format: audience, key change, and one customer example.”

CodexNext draft

“I found the brief-writing skill. I’ll use those three sections for this draft.”

Claude CodeConnected tool

“Add our research server to Loop so we can reuse it for the brief.”

CodexNext research pass

“The research connection is available to me. I’ll look up the interview notes.”

Agent setup

Start with
your agent.

Choose the agent you already use and connect it to Loop. You can bring in another whenever you need it.

Set up in your browser ↗
1
Paste this in your terminal
claude mcp add --transport http --scope user loop https://useloop.sh/mcp
2
Type /mcp, pick loop, choose Authenticate
Sign in with Google or email. That creates your Loop account. Loop opens the sign-in flow in your browser.
✓
Done. Claude Code is in your Loop.
Ask it to “add my remote MCP servers to Loop”, or paste your config with Import JSON in Loop.
1
Add Loop
codex mcp add loop --url https://useloop.sh/mcp
2
Sign in
codex mcp login loop
Your browser opens. Sign in with Google or email to create your Loop account.
✓
Done. Codex is in your Loop.
1
Add this to ~/.cursor/mcp.json
{ "mcpServers": { "loop": { "url": "https://useloop.sh/mcp" } } }
2
Open Cursor Settings → MCP, click Connect next to loop
Sign in with Google or email. That creates your Loop account.
✓
Done. Cursor is in your Loop.
1
Add a remote MCP server with this URL
https://useloop.sh/mcp
Any app that supports remote MCP with OAuth will ask you to sign in. For apps that only take a key, sign up on the web and use Connect to get one.
1
Install free Local Loop (macOS / Linux)
curl -fsSL https://useloop.sh/install.sh | sh
2
Start Loop locally
loop start
Runs 100% locally on 127.0.0.1:8799 under AGPL-3.0 with unlimited local agents and connections. Pair with Loop Connect anytime to share across devices.
